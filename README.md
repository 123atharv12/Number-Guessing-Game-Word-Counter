
# Number Guessing Game & Word Counter

A beginner-friendly Python project with two tools.

## Features
- Random number guessing game
- Attempt counter and scoring
- Reads text from a file
- Counts total words and word frequency
- Handles invalid input and missing files

## Requirements
Python 3

## How to Run
Run `main.py` using Python 3.
Keep `sample.txt` in the same folder.
